Vice Cover Studio turns your photo and caption into GTA 6-style multi-panel cover art with a Vice City sunset or neon colour grade, exported as PNG in 1080×1080, 1080×1350 and 1920×1080. It runs offline in a desktop browser from its own files.

## Run it

```sh
node serve.ts
```
